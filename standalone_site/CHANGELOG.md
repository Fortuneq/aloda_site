# Changelog - Обновление лендинга ALODA

## Версия 2.0 - 22 октября 2025

### 🎨 Визуальные улучшения

#### 1. ИИ-мозг на главном экране
- ✅ Заменена волна на анимированную визуализацию нейронной сети
- ✅ 60+ узлов с пульсирующими соединениями
- ✅ Два полушария мозга с градиентом red→purple
- ✅ Плавная анимация с центральным пульсом
- ✅ Оптимизирована для desktop (только >768px)

**Технические детали:**
- Canvas API для рендеринга
- Градиентные линии между узлами
- Физика движения с возвратом к исходной позиции
- 60 FPS анимация

#### 2. Улучшенный дизайн отзывов
- ✅ Градиентный фон карточек (белый → светло-серый)
- ✅ Динамическая градиентная граница сверху при hover
- ✅ Увеличенные аватары (80px) с градиентной обводкой
- ✅ Улучшенная типографика (курсив для текста)
- ✅ Эффект обесцвечивания логотипов с восстановлением при hover
- ✅ Более выраженные тени и lift-эффект

**Новые эффекты:**
- Градиентная верхняя граница (появляется при hover)
- Увеличенный подъем карточки (-8px вместо -4px)
- Gradient border на аватаре
- Большая кавычка справа с gradient fill

### 🐛 Исправления багов

#### Услуги и ценники
- ✅ Исправлен баг с атрибутом `hidden="false"` (некорректное значение)
- ✅ Добавлена плавная transition при переключении табов
- ✅ Использован `display: block/none` вместо только `hidden`
- ✅ Force reflow для корректного срабатывания анимаций
- ✅ Задержка перед скрытием для fade-out эффекта

**До:**
```html
<div hidden="false"> <!-- Неправильно -->
```

**После:**
```html
<div class="fade-in is-visible"> <!-- Правильно -->
```

### 📱 Адаптивность

- ✅ ИИ-мозг: упрощенная версия на mobile (меньше opacity)
- ✅ Отзывы: адаптивные размеры карточек
- ✅ Табы: улучшенная читаемость на маленьких экранах

### 🚀 Производительность

- Оптимизирована анимация мозга (ограничено кол-во соединений)
- GPU acceleration для transform эффектов
- RequestAnimationFrame для плавных 60fps
- Conditional loading: мозг загружается только на desktop
